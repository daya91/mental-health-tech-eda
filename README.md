# Mental Health in Tech Workplace: Exploratory Data Analysis

This project analyzes the Mental Health in Tech Survey dataset.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Topics
- Mental health treatment
- Family history and treatment
- Mental health interference with work
- Employer mental health benefits
- Willingness to discuss mental health with supervisors
